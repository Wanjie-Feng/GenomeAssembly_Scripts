# GenomeAssembly_Scripts

> A collection of modular shell scripts for genome assembly and annotation, optimized for *Brassica napus* (rapeseed).

![Shell](https://img.shields.io/badge/language-Shell-green?logo=gnu-bash)
![License](https://img.shields.io/badge/license-BSD--3--Clause-blue)

## 📌 Overview

This repository provides a set of automated, modular shell scripts to streamline the **genome assembly** and **functional annotation** pipeline for *Brassica napus*, a complex allotetraploid crop species. The workflow supports long-read sequencing technologies and integrates widely used bioinformatics tools for high-quality genome reconstruction and annotation.

## 🗂️ Repository Structure
```
GenomeAssembly_Scripts/
├── assembly/ # Scripts for genome assembly (e.g., hifiasm)
├── annotation/ # Scripts for genome annotation (repeat masking, gene prediction, functional annotation)
└── LICENSE # BSD 3-Clause License
```
